# Changelog

## Unreleased
- Add visible six-dot drag grips in settings, pointer-following previews and
  animated space-making feedback in settings and both live dock orientations.
- Drag applications and separators to reorder them in settings and on the live
  dock, including both orientations and the shortcut pop-up.
- Synchronize launcher names and icons with external `.desktop` file changes,
  preserving dock customizations and recovering from missing or invalid files.
- Improve application settings with launcher name, icon and desktop-file editing,
  file validation, duplicate feedback and labeled editing/reordering controls.
- Add reorderable spacers and Latte-style separator bars, including editing,
  both dock orientations and the shortcut pop-up.

## 1.1.0
- Automatically increment numeric SemVer build metadata when packaging.
- Add applications by dropping local `.desktop` files onto either dock view, with
  drag feedback, duplicate prevention and import errors.

## 1.0.0
- First release: app picker and reordering, icon magnification, launch bounce,
  frosted-glass shelf with tint/blur/sheen settings, horizontal or vertical layout,
  and a shortcut-activated pop-up copy that shows above open windows.
